# Container firewall allowlist — project-maintained baseline.
#
# One entry per line: a domain name (DNS A record is resolved) or an
# IPv4 CIDR block. Lines starting with `#` and blank lines are ignored.
# Whitespace is trimmed.
#
# This file is mounted read-only into the container at
# /etc/oas/firewall-baseline.txt and baked into the image as a fallback
# so the container works even if the mount is missing.
#
# These are the domains required for normal Claude Code operation.
# To add project-specific or personal extras, edit firewall-extras.txt
# or use the "Additional firewall domains" setting in the Obsidian plugin.
#
# Changes take effect on the next container start (or after rerunning
# /usr/local/bin/init-firewall.sh inside the container).
