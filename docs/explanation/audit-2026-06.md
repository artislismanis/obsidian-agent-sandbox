# Codebase audit, June 2026

**TL;DR:** a full review of `plugin/`, `container/`, `workspace/`, and `docs/` found no high-severity bugs. The codebase is in good shape: strict shell modes, deep defensive guards in the plugin, accurate docs. The audit produced eight small fixes (applied) and three recorded recommendations. It also rejected six plausible-looking "bugs" that turned out to be deliberate design; they are listed here so future reviews do not re-chase them.

## Scope and method

Three parallel reviews covered the plugin, the container and workspace, and docs-vs-code consistency. Every candidate finding was then verified against source before action. Severity below reflects the verified state, not the initial reports.

## Recommended, not actioned

- **Repeated defaults across infra files.** `agent-workspace`, `memory.json`, and ports 7681/28080 each appear in three to five files. Compose's `${VAR:-default}` idiom blocks full centralisation. `container/CLAUDE.md` gained a "Changing a default value" section listing every site per default; treat that list as the checklist when changing one.
- **`terminal-view.ts` decomposition.** At ~960 lines it combines xterm lifecycle, WebSocket protocol, reconnect, and prompt injection. It is correct and commented; split into view and connection classes only when a feature demands it.
- **Reconnect-exhaustion coverage.** The decision is unit-tested via `reconnectDelayMs`; the surrounding `scheduleReconnect()` wiring stays e2e-only, an accepted gap shared with the rest of the Obsidian-API-bound modules (see `plugin/CLAUDE.md`, Testing).

## Checked and rejected

Each of these looked like a bug on first read and is not. Do not "fix" them.

- `activity.ts` `workspace.offref(ref)`: the correct Obsidian API for detaching an `EventRef`.
- `notify-status.sh` exits 0 on jq or proxy failure: documented silent-failure contract; a status hook must never block Claude Code (header comment, lines 5-6 and 28-29).
- `main.ts.onunload()` ordering (MCP shutdown, activity clear, debounce cancel, explicit save, leaf detach): correct and documented as load-bearing in the method body.
- MCP start-failure UX in `mcp-lifecycle.ts`: the Notice includes `errMsg(error)`, and `mcpEnabled` records user intent rather than runtime state, so a transient failure must not flip it.
- Terminal WebSocket "listener races": `attachWebSocket()` tears down prior listeners via `wsDispose`, every async callback checks the generation counter, and `onClose` guards on `this.ws !== ws`.
- Settings restart-prompt "race": snapshot-at-display, compare-at-hide is the intended diff model (covered by `settings-restart.test.ts`).
