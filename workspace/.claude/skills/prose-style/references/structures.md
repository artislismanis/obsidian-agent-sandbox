# Structures to avoid

Patterns that read as AI even when individual words are fine.

## Binary contrasts

Telegraphed reversals. State the conclusion directly.

| Pattern | Problem |
| --- | --- |
| "Not because X. Because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "It feels like X. It's actually Y." | Setup/reveal cliché |
| "The question isn't X. It's Y." | Rhetorical misdirection |
| "Not X. But Y." | Mechanical contrast |
| "stops being X and starts being Y" | False transformation |
| "doesn't mean X, but actually Y" | Negation crutch |
| "not just X but also Y" | Additive hedge |

**Fix:** State Y directly. Drop the negation entirely.

## Negative listings

Listing what something is *not* before revealing what it *is*. Rhetorical
striptease.

| Pattern |
| --- |
| "Not a X. Not a Y. A Z." |
| "It wasn't X. It wasn't Y. It was Z." |

**Fix:** State Z. The reader does not need the runway.

## Dramatic fragmentation

Sentence fragments for emphasis read as manufactured profundity.

| Pattern |
| --- |
| "[Noun]. That's it. That's the [thing]." |
| "X. And Y. And Z." |
| "This unlocks something. [Word]." |

**Fix:** Complete sentences. Trust the content.

## Rhetorical setups

These announce insight instead of delivering it.

| Pattern |
| --- |
| "What if [reframe]?" |
| "Here's what I mean:" |
| "Think about it:" |
| "And that's okay." |

**Fix:** Make the point. Let the reader draw the conclusion.

## False agency

Inanimate things doing human verbs. AI loves this because it avoids
naming the actor.

| Pattern | Fix |
| --- | --- |
| "a complaint becomes a fix" | "the team fixed the issue" |
| "a bet lives or dies in days" | "we kill or ship in days" |
| "the decision emerges" | "the lead engineer decides" |
| "the culture shifts" | "people change their behaviour" |
| "the data tells us" | "we read the data as..." |
| "the market rewards" | "buyers pay for" |

**Fix:** Name the human. If no specific person fits, use "we" or "you".

## Passive voice

Every sentence needs a subject doing something. Passive voice hides the
actor and drains energy.

| Pattern | Fix |
| --- | --- |
| "X was created" | Name who created it |
| "It is believed that" | Name who believes it |
| "Mistakes were made" | Name who made them |
| "The decision was reached" | Name who decided |

**Exception:** Passive is fine when the actor is unknown or irrelevant
("the file was last modified in March").

## Sentence openers

Avoid starting with:

- What, When, Where, Which, Who, Why, How (restructure)
- So, Look, Now, Well (cut)

"What makes this hard is..." → "The constraint is..." → best: name the
specific constraint.

## Three-item lists

The rule of three is a writing cliché. Prefer two items, or one, unless
three is the actual count.

| Pattern | Fix |
| --- | --- |
| "fast, cheap, and reliable" | Pick the two that matter |
| "X, Y, and Z" (when X and Y suffice) | Cut Z |

If you have four or more items, use bullets.

## Rhythm patterns

| Pattern | Fix |
| --- | --- |
| Questions answered immediately | Cut the question. Lead with the answer. |
| Every paragraph ends punchily | Vary endings. |
| Em dashes | Use commas, colons, or full stops. |
| Staccato fragmentation | Vary sentence length. |
| Metronomic same-length sentences | Mix lengths. |

## When to add to this list

A pattern belongs here when:

- It sounds formulaic across multiple examples, AND
- Substituting direct prose improves the result, AND
- You can name the fix (not just the problem).

Document the pattern, the problem, and the fix in a table row.
